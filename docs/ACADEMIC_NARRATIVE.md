# 论文叙事大纲

> 本文档是写作用的叙事骨架；实验设置、数据、表格与图表以 [`EXPERIMENT.md`](EXPERIMENT.md) 为准。

## 1. 研究背景与瓶颈

城市交通数字孪生的可信度，取决于微观仿真（SUMO）能否复现真实交通的宏观统计与微观行为。微观跟驰 / 换道参数（10 维）的联合标定是典型的 **昂贵黑盒优化**：单次评估即需一次完整 TraCI 闭环仿真，参数维度不低、目标景观非凸且随场景剧变。全局启发式（GA）与局部梯度法（SPSA）在百次量级预算内都难以兼顾「全局看准」与「不浪费仿真」。

## 2. 核心假设

在昂贵仿真约束下提升样本效率的关键，是注入 **交通领域先验**：用低维、可解释的行为表征替代逐点轨迹比对，使「参数 → 响应」更平滑可学；再用少量精心设计的真仿真训练代理，以序贯采集把剩余预算集中到最有希望的区域，而非一次性耗尽于均匀或随机试探。

## 3. 方法：FLAT

统一最小化 8 维行为指纹加权误差 $J_b$，固定 100 次 SUMO 预算（40 LHS + 60 序贯 LCB，κ 2.0→0.5 退火）。

- **领域特征化**：从真实 / 仿真轨迹提取 8 维行为指纹（速度水平 / 分位、加减速强度、停车占比…），平滑并结构化黑盒目标，为代理提供稳定监督信号。
- **代理 + 序贯采样**：LHS 初始设计后训练回归代理，按下置信界 LCB 在信赖域 + 全局候选中选点，真仿真验证并入库，循环至预算用尽。
- **可插拔代理**：随机森林（默认）或 MLP 深度集成，序贯机制共用；框架对代理选择不敏感。
- **场景自适应**：参数边界与指纹权重按场景调整，避免「一套参数走天下」。

## 4. 实验验证

- **数据 / 场景**：基于 SIND 与 UTE 真实轨迹的六个异构场景（三信号交叉口 + 三城市快速路）。
- **公平对比**：统一 100 次预算、5 seed，FLAT（RF / MLP）对四个机制各异的基线 SPSA / GA / CMA-ES / TPE。
- **主要发现**（详见 `EXPERIMENT.md`）：FLAT 跨四种范式一致领先，优势首先来自预算内的稳健性；RF 与 MLP 大体等价，MLP 仅在响应面崎岖的难场景兑现增益；N_init 消融表明序贯 LCB 真实优于纯 LHS；部分场景（如西安）存在由指纹—参数固有失配决定的不可约误差下界。

## 5. 贡献

1. **问题刻画**：将微观交通标定刻画为「昂贵仿真约束下的 10 维黑盒优化」，以 $J_b$ 与固定预算固定评价口径。
2. **方法贡献**：提出 FLAT——行为指纹降维 + 可插拔代理 + LHS 初始设计 + 序贯 LCB，开源对接 SUMO–TraCI。
3. **实证贡献**：在六类真实异构场景上完成标定与公平对比，证明「领域特征化 + 代理序贯决策」在百次仿真量级内稳健优于四种异构基线。
