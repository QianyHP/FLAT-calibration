# Reproduction

Install `requirements.txt` in Python 3.10+ and add SUMO to `PATH` for simulation runs.

## Predictive scores

```bash
python code/experiments/analyze_predictive_scores.py
python code/experiments/analyze_predictive_scores.py --from-predictions
```

The first command fits 20 GPs on the saved 400-point landscapes: two scenes,
two objectives, five training subsets, 100 training points and a fixed
100-point holdout. It reproduces the archived raw scores, then reports NLL and
CRPS on each training subset's response scale. A constant Gaussian estimated
from the same training responses supplies the reference scores. The second
command recomputes reference comparisons from saved predictions without fitting.

Outputs are in `outputs/results/probability_score_audit/`: fit-level scores,
training moments, aggregate diagnostics, predictions and split indices. The
published summaries include all four scene/objective comparisons. Predictions
and split indices are regenerated by the first command rather than stored twice.

## Fixed-parameter replay

```bash
python code/experiments/analyze_replay_surrogates.py
python code/experiments/run_replay_surrogates.py --preflight
python code/experiments/run_replay_surrogates.py --workers 4 --resume
```

The analysis uses the published 720 replay records: six scenes, three FLAT
backends, four original optimization runs and ten shared simulation seeds.
Average the ten simulations within each fixed parameter set before comparing
optimization runs. These seeds generate new simulation realizations of the
same scenes. The published replay covers the three FLAT backends.

The runner loads 72 parameter vectors from the manifest. Preflight checks the
scene inputs and SUMO version; explicit `--resume` validates saved records and
runs missing jobs. Supply the original SinD/UTE data and derived scene files
listed in the manifest under their upstream licenses. The manifest retains the
original source hashes and the 144 reused / 576 new computation accounting.

## Evaluation cost

```bash
python code/experiments/measure_evaluation_cost.py --output outputs/results/evaluation_cost_new
```

This serial measurement uses the published GP final parameters from optimization
run 101 and three shared SUMO seeds, 20001--20003, on all six scenes. Timing
includes process startup, TraCI collection, fingerprint extraction and scoring.
Reference extraction and surrogate fitting are outside this evaluation timer.
The recorded measurements and hardware are in `outputs/results/evaluation_cost/`.
Use a new output directory for a new measurement.

## Reference weights

```bash
python code/calibration/compute_ivw_weights.py --output outputs/results/ivw_reference_weights.json
```

The utility computes per-vehicle reference variances and normalized inverse
variance weights. It uses SI feature units and writes the weights and sampling
metadata to JSON. Zero variance requires an explicit positive `--variance-floor`.
Calibration defaults are unchanged by running this utility.

## Main-result figures

```bash
python code/experiments/plot_calibration_convergence.py
python code/experiments/plot_method_comparison.py
```

These plots read the frozen `comparison_convergence_main.csv` and
`comparison_summary_main.csv`, rather than mutable simulation caches. The
calibration panels use saved final-training-set R² labels from
`surrogate_fit_metrics.csv`; these are distinct from the appendix holdout scores.
Paper panel PDFs are written to `paper/figure/` and mirrored to the matching
paths under `outputs/figures/`.

## Main experiments and environment

The calibration module provides GP, RF and MLP backends. Main comparison CSVs,
baseline caches and figure entry points are under `outputs/` and
`code/experiments/`. The score and replay analyses reuse these saved experiments.

Exact GP score reproduction used Python 3.13.2, NumPy 1.26.4, pandas 2.3.3,
SciPy 1.15.2, scikit-learn 1.8.0, joblib 1.5.2, matplotlib 3.10.1 and
threadpoolctl 3.6.0. The score verification stops if the original raw scores do
not reproduce. `requirements.txt` remains the installation entry point.
